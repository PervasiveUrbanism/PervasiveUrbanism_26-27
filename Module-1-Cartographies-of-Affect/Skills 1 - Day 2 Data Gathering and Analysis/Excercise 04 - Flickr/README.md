# Flickr API — Preparation

## Flickr Pro subscription and API key

To run the live searches in the Flickr API tutorial, **each student needs a Flickr Pro subscription and their own API key**. Flickr currently restricts requests for new API keys to Pro subscribers. Sign in to Flickr (or create an account), subscribe to Pro, then visit the [Flickr API Keys page](https://www.flickr.com/services/api/keys/) and apply for a **non-commercial key** for educational use. Applications are reviewed, so make these arrangements before the workshop. Keep your API key and API secret private: do not publish them on GitHub or include them in a submitted notebook.

See [Flickr's official API instructions](https://www.flickrhelp.com/hc/en-us/articles/4404070036884-Flickr-API).
