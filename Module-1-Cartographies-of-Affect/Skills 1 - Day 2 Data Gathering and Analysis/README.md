# Data Gathering and Analysis — Day 2

This session introduces four connected exercises, moving from working with existing datasets to collecting data from an API, analysing text and designing AI-assisted research workflows.

1. **[Exercise 01 — Pandas](Exercise%2001%20-%20Pandas/Exercise%2001%20-%20Pandas.ipynb)** — load, inspect, filter and export tabular data.
2. **[Exercise 02 — Flickr API](Exercise%2002%20-%20Flickr%20API/Exercise%2002%20-%20Flickr%20API.ipynb)** — request geotagged photographs, handle JSON and pagination, and map results with Folium. [Preparation and API credentials](Exercise%2002%20-%20Flickr%20API/README.md).
3. **[Exercise 03 — Sentiment Analysis](Exercise%2003%20-%20Sentiment%20Analysis/Exercise%2003%20-%20Sentiment%20Analysis.ipynb)** — compare TextBlob, VADER and an optional transformer approach, and score a Pandas column.
4. **[Exercise 04 — Agentic Coding](Exercise%2004%20-%20Agentic%20Coding/README.md)** — evaluate agentic search and develop a controlled, testable data-collection workflow.

Work through the exercises in sequence. Each introduces concepts that will be useful in your own urban-data investigation.
